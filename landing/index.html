How to install (unpacked)

If you download the ZIP or clone the repo, install the extension locally in Chrome:

  1. Open chrome://extensions and enable Developer mode.
  2. Click Load unpacked and choose the extension folder (the folder that contains manifest.json).
  3. The extension will appear in your toolbar — click it to open the popup and start composing.

Full instructions are included in INSTALL.md in the repo.
