# INSTALL.md

Thank you for checking out AI Post Composer (MVP).

This file explains how to install the extension locally (unpacked) and what to expect when you download it from Gumroad or the repository.

IMPORTANT: The Chrome Web Store requires a one-time $5 developer fee to publish publicly. This unpacked installation method lets you install the extension immediately without paying that fee.

Steps to install the unpacked extension (Windows / macOS / Linux):

1. Download and unzip the extension package (ai-post-composer.zip) or clone the repo:
   - git clone https://github.com/madhugurjar954-cloud/ai-post-composer.git

2. Open Google Chrome and go to:
   - chrome://extensions

3. Enable "Developer mode" (toggle in the top-right).

4. Click "Load unpacked" and select the folder that contains the extension files (the folder with manifest.json). If you downloaded a ZIP, unzip it first and select the unzipped folder.

5. The extension will appear in the extensions toolbar. Click the extension icon to open the popup and start composing posts.

Quick troubleshooting:
- If the popup shows a blank area, ensure manifest.json and popup.html are in the selected folder root.
- If Chrome blocks loading, check your OS security settings (macOS may require you to allow Chrome to run unsigned extensions).
